# PowerA - Guide d'Installation Complet\n\n## Prérequis\n\n### Node.js et npm\n**Télécharger et installer depuis :**\n- https://nodejs.org/en/download/\n- (Choisir la version LTS)\n\n**Vérifier l'installation :**\n```bash\nnode --version\nnpm --version\n```\n\n---\n\n## Installation PowerA\n\n### 1. Cloner le projet\n```bash\ngit clone https://github.com/Adjobi783/electricity-project.git\ncd electricity-project\n```\n\n### 2. Installer les dépendances\n```bash\nnpm install\n```\n\nCela installe automatiquement :\n- **express** (serveur web)\n- **sqlite3** (base de données)\n- **bcryptjs** (chiffrement des mots de passe)\n- **express-session** (gestion des sessions)\n- **nodemon** (développement)\n\n### 3. Démarrer l'application\n```bash\nnpm start\n```\n\n**Ou pour le mode développement (avec rechargement automatique) :**\n```bash\nnpm run dev\n```\n\n### 4. Accéder à PowerA\nOuvrir dans votre navigateur :\n- http://localhost:3000\n\n---\n\n## Identifiants de Connexion par Défaut\n\n**Email :** admin@powera.local  \n**Mot de passe :** Admin123!\n\n---\n\n## Dépendances npm Utilisées\n\n| Package | Version | Lien | Utilité |\n|---------|---------|------|----------|\n| express | ^4.19.2 | https://www.npmjs.com/package/express | Serveur web |\n| sqlite3 | ^5.1.7 | https://www.npmjs.com/package/sqlite3 | Base de données |\n| bcryptjs | ^2.4.3 | https://www.npmjs.com/package/bcryptjs | Hachage des mots de passe |\n| express-session | ^1.18.0 | https://www.npmjs.com/package/express-session | Gestion des sessions |\n| nodemon | ^3.1.19 | https://www.npmjs.com/package/nodemon | Rechargement automatique |\n\n---\n\n## Architecture PowerA\n\n### Backend (Node.js + Express + SQLite)\n- `server.js` - Serveur principal\n- `data/powera.db` - Base de données SQLite\n\n### Frontend (HTML + CSS + JavaScript)\n- `public/index.html` - Interface utilisateur\n- `public/style.css` - Styles CSS\n- `public/app.js` - Logique client\n\n### Fonctionnalités Principales\n\n**Phase 1 - Gestion de Base**\n- Enregistrement des entreprises\n- Saisie des consommations électriques\n- Enregistrement des coupures\n- Calculs de coûts en FCFA\n\n**Phase 2 - Authentification & Sécurité**\n- Système de connexion/enregistrement\n- Rôles utilisateur (admin/manager)\n- Sessions sécurisées\n- Chiffrement des mots de passe\n\n**Phase 3 - Analyses & Graphiques**\n- Graphiques mensuels\n- Répartition par source d'énergie\n- Analyses des coupures\n- Recommandations automatiques\n\n---\n\n## Dossiers Importants\n\n```\nelectricity-project/\n├── server.js              # Serveur principal\n├── package.json           # Dépendances npm\n├── public/                # Frontend\n│   ├── index.html\n│   ├── style.css\n│   └── app.js\n├── data/                  # Base de données\n│   └── powera.db\n└── node_modules/          # Dépendances installées\n```\n\n---\n\n## Dépannage\n\n### Port 3000 déjà utilisé ?\n```bash\n# Utiliser un autre port\nPORT=3001 npm start\n```\n\n### Erreur \"npm: command not found\" ?\n- Réinstaller Node.js depuis https://nodejs.org/en/download/\n\n### Erreur de base de données ?\n```bash\n# Supprimer le dossier data et recommencer\nrm -rf data/\nnpm start\n```\n\n---\n\n## Support\n\nPour toute question :\n- GitHub : https://github.com/Adjobi783/electricity-project\n- Email : adjobi0708hippo@gmail.com\n"
